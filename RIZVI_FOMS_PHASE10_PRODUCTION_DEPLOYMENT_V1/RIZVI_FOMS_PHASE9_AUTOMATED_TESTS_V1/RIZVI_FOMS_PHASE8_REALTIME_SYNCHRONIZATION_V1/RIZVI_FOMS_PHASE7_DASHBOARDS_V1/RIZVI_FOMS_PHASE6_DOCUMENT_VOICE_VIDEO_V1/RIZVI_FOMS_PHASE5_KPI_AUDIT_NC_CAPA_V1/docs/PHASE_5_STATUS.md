# Phase 5 — KPI, Audit, NC/CAPA

## Implemented database structures
- KPI definitions, targets and measurement periods
- Audit programs
- Audit findings with classification
- Nonconformity register
- CAPA register
- Root-cause fields
- Corrective and preventive actions
- CAPA action tracking
- Due dates and ownership
- Effectiveness review fields
- Verification and closure controls
- Audit trace records

## Implemented business rules
- KPI operator evaluation
- CAPA state-transition validation
- Effectiveness-review closure gate
- Audit finding classification validation
- NC-required rule for Minor/Major NC findings

## Control flow
Audit Finding → NC (where applicable) → Investigation / Root Cause → Action → Implementation → Effectiveness Review → Verification → Closure.
